# Security Policy

The security of AlphaConstruct and its users is taken seriously.

Responsible disclosure helps protect users while allowing sufficient time to investigate and resolve confirmed vulnerabilities before they are made public.

<br>

## Supported Versions

Security updates are provided for the latest released version of AlphaConstruct.

If you discover a security issue in an older version, please verify whether the issue is still present in the latest release before reporting it.

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in AlphaConstruct, please do **not** open a public GitHub issue.

Instead, please report it privately by contacting:

**<suus@vertexcuriosity.com>**

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected version of AlphaConstruct.
- Any proof-of-concept or supporting information, if available.

I will acknowledge receipt of your report as soon as reasonably possible and investigate the issue.

If the vulnerability is confirmed, I will work to resolve it or, where appropriate, coordinate with the maintainers of any affected third-party software.

## Scope

This policy applies only to the official AlphaConstruct project and its published releases.
